## 🚀 快速使用教程

本仓库仅展示模板案例源码，在线可视化编辑、一键生成源码请前往官方引擎：

官方网站：https://www.402.cn

1. 打开筑码引擎官网，进入模板中心

2. 搜索对应行业Demo模板，一键载入可视化画布

3. 拖拽组件自由修改页面内容、样式、布局，所见即所得

4. 编辑完成一键生成、下载完整PHP项目源码

5. 上传自有服务器，访问 `install.php` 完成一键安装部署

6. 导入微信开发者工具即可发布小程序，同时支持H5全网访问
